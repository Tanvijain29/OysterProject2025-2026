### Eastern Oyster Metapopulation Analysis

#### Overview

# 

This repository contains data and analysis scripts used to study population dynamics of the eastern oyster (Crassostrea virginica) with a focus on metapopulation structure, migration rates, and demographic patterns. The goal of this project is to better understand how oyster populations are connected across locations and how environmental or spatial factors influence population persistence.



The analyses include data processing, statistical modeling, and visualization of oyster population patterns.
